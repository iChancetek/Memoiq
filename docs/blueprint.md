# **App Name**: MemoIQ

## Core Features:

- Dashboard: Central dashboard providing an overview of the user's day, upcoming events, and recent memos.
- Voice Memos: Voice memos automatically transcribed, summarized, and tagged using AI.
- Task Management: A clean UI to manage and track to-do items.
- AI Assistant iSkylar: Interactive AI assistant, iSkylar, offering personalized insights, reminders, and natural language interaction; the tool can also schedule changes.
- Quick Add: Quickly add tasks, contacts, memos, and events with an accessible panel.

## Style Guidelines:

- Primary color: Deep blue (#191970) to reflect intelligence and calm, resembling the iSkylar interface.
- Background color: A darker shade of blue (#000080), similar to iSkylar's background, creating a consistent and sophisticated backdrop for the entire application.
- Accent color: A light purple (#E6E6FA) as a button to set off the UI elements nicely, inspired by the iSkylar button.
- Body and headline font: 'Inter' (sans-serif) for a modern and neutral feel, providing readability and a clean aesthetic.
- Use clean and modern icons to represent different actions and categories within the app.
- Dashboard-centric layout with modular cards and collapsible side navigation for optimal content consumption.
- Smooth, subtle animations and transitions using Framer Motion to enhance user experience and provide visual feedback.
